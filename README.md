# Vaha gaye the?

A tiny fun page: **"Vaha gaye the?"** with **Yes**, **No**, and **Kahan**.

- **Yes** → removes Yes, moves **Kahan** to a random spot on the screen  
- **No** → removes No, moves **Kahan** elsewhere  
- **Kahan** → full-screen **YAHANN**

## Live link (after GitHub Pages setup)

Create a repo named **`vaha-gaye-the`** on GitHub, upload these files, enable Pages on `main`:

**https://amaanaj04-ux.github.io/vaha-gaye-the/**

(Replace `amaanaj04-ux` if your username is different.)

## Deploy

1. New repo on GitHub: `vaha-gaye-the`
2. Upload `index.html`, `styles.css`, `script.js`
3. **Settings → Pages** → branch `main`, folder `/ (root)`
4. Open the link above after 1–2 minutes
